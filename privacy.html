Privacy Policy

Last updated: 28 October 2026

YouTube API Services

Discovery Lab uses YouTube API Services. By using Discovery Lab you agree to be bound by the YouTube Terms of Service. Information obtained through YouTube API Services is also subject to the Google Privacy Policy.

Who uses it

Discovery Lab is a private tool used only by its owner to analyse the owner's own YouTube channels. It is not offered to the public.

What information is accessed

  • Own channel analytics (with the owner's Google authorization): read-only YouTube Analytics and Reporting data for the owner's channels, such as views, engaged views, watch time, average view duration, traffic sources, and thumbnail impressions and click-through rate. The only permission requested is https://www.googleapis.com/auth/yt-analytics.readonly.
  • Public YouTube data: public metadata and statistics of videos and channels (for example titles, publication dates, view and subscriber counts) obtained through the YouTube Data API with an API key.

Discovery Lab does not access passwords, payment information, private messages, or any data of other YouTube users beyond what YouTube makes public.

How information is used

Only to produce private research reports for the owner about content performance and emerging content formats.

Storage and retention

  • All data is stored locally on the owner's computer. Nothing is stored on external servers by Discovery Lab.
  • Public YouTube data is deleted or refreshed within 30 days, in line with the YouTube API Services Developer Policies.
  • The owner's own channel analytics are kept only while the owner's authorization remains active.
  • Authorization tokens are stored in the operating system's secure keychain.

Sharing

Discovery Lab does not share, sell, or transfer any information to third parties. It does not use cookies and does not place tracking technologies on any device.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page. To request deletion of any stored data, open an issue at github.com/finfreedom/discovery-lab/issues; data is deleted within 7 days of the request.

Changes

Any change to this policy is published on this page with a new date.
