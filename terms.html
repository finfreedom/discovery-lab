The service

Discovery Lab is a private research tool operated by its owner, Nikita Borodin, for the owner's own use. It is not offered, sold or distributed to anyone else, and there is no sign-up.

YouTube API Services

Discovery Lab uses YouTube API Services. Anyone using Discovery Lab agrees to be bound by the YouTube Terms of Service. Information obtained through YouTube API Services is subject to the Google Privacy Policy. How Discovery Lab accesses, uses, stores and deletes information is described in its Privacy Policy.

Permitted use

  • Discovery Lab only reads data. It does not upload, edit or delete videos, comments, playlists or channel settings.
  • It uses only official YouTube API Services and does not scrape YouTube.
  • Its reports are private to the owner and are not published, shared or sold.
  • Metrics that Discovery Lab calculates itself are labelled as its own estimates, not as data provided by YouTube.

Authorization

Access to a channel's analytics requires the channel owner's Google authorization with the read-only permission https://www.googleapis.com/auth/yt-analytics.readonly. It can be revoked at any time on the Google security settings page.

No warranty

Discovery Lab is provided as is, without warranty of any kind.
