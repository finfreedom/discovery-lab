Discovery Lab

A private, single-user research tool. Not a public service.

What it does

  • Reads analytics of the owner's own YouTube channels (read-only) through the YouTube Analytics API and YouTube Reporting API, to understand which videos perform and why.
  • Reads public metadata and statistics of recently published YouTube videos through the YouTube Data API, to study how content formats emerge.

What it does not do

  • It does not upload, edit or delete videos, comments or channel settings.
  • It does not scrape YouTube; it uses only official YouTube API Services.
  • It does not share or sell any data, and it has no users other than the owner.

Discovery Lab uses YouTube API Services. By using it you agree to the YouTube Terms of Service.
